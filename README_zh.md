# NetTopo 3D

[English](README.md) | [中文](README_zh.md)

一个使用Three.js构建的3D网络拓扑可视化工具，允许用户在三维空间中创建、可视化和交互网络拓扑。

## 功能特点

- **交互式3D可视化**：在完全交互式的3D环境中查看网络拓扑
- **多种设备类型**：创建具有详细3D模型的路由器、交换机和PC
- **设备连接**：通过可视化链接轻松连接网络设备
- **示例拓扑**：加载预配置的示例拓扑进行演示
- **自定义命名**：为设备命名以便更好地组织
- **选择与高亮**：选择设备以高亮显示，用于连接或检查
- **现代UI**：干净、响应式的界面，直观的控制

## 使用的技术

- **Three.js**：用于3D渲染和场景管理
- **JavaScript (ES6+)**：核心编程语言
- **HTML5/CSS3**：结构和样式
- **Font Awesome**：用于UI图标

## 开始使用

### 前提条件

- 支持WebGL的现代网络浏览器（Chrome、Firefox、Safari、Edge）
- 无服务器端要求 - 完全在浏览器中运行

### 安装

1. 克隆此仓库：
   ```
   git clone https://github.com/zym9863/nettopo-3d.git
   ```

2. 在网络浏览器中打开`index.html`

或者，您可以使用本地开发服务器：

```
npx http-server
```

然后在浏览器中导航到`http://localhost:8080`。

## 使用方法

### 添加设备

1. 点击右侧面板中的一个设备按钮：
   - 路由器
   - 交换机
   - PC

2. 设备将被添加到场景中的随机位置

### 连接设备

1. 点击"连接设备"按钮进入连接模式
2. 点击要连接的第一个设备
3. 点击第二个设备创建连接
4. 创建连接后，连接模式将自动退出

### 加载示例拓扑

- 点击"加载示例"按钮加载预配置的网络拓扑

### 清除拓扑

- 点击"清除所有"按钮移除所有设备和连接

### 导航

- **旋转**：使用鼠标左键点击并拖动
- **平移**：使用鼠标右键点击并拖动或使用鼠标中键
- **缩放**：使用鼠标滚轮

## 项目结构

```
nettopo-3d/
├── css/
│   └── style.css              # 主样式表
├── js/
│   ├── models/                # 网络设备模型
│   │   ├── NetworkNode.js     # 所有网络设备的基类
│   │   ├── Router.js          # 路由器实现
│   │   ├── Switch.js          # 交换机实现
│   │   ├── PC.js              # PC实现
│   │   └── Connection.js      # 设备间的连接
│   ├── utils/
│   │   └── LabelUtils.js      # 创建3D文本标签的工具
│   ├── SceneManager.js        # 管理Three.js场景
│   ├── TopologyManager.js     # 管理网络拓扑
│   ├── UIController.js        # 处理UI交互
│   └── main.js                # 应用程序入口点
└── index.html                 # 主HTML文件
```

## 自定义

### 添加新设备类型

1. 在`js/models/`目录中创建一个扩展`NetworkNode`的新类
2. 实现`createMesh()`方法来定义3D表示
3. 更新UI以包含新设备类型的按钮

### 修改设备外观

编辑相应的设备类文件（例如，`Router.js`、`Switch.js`、`PC.js`）以更改3D模型外观。

### 更改颜色

可以通过更新`:root`选择器中的CSS变量来修改`css/style.css`文件中的配色方案。
